# 📍 GEO TRACKER & DASHBOARD

Sistema de captura de ubicaciones en campo y monitoreo geográfico en tiempo real mediante **PWA**, **Google Apps Script** y **Leaflet JS**.

## 🚀 Características
* **Captura PWA:** PWA offline/online con compresión automática de fotografías en formato JPEG para optimizar datos móviles.
* **Backend sin servidor:** Integración con Google Apps Script para el procesamiento de coordenadas e imágenes guardadas directamente en Google Drive y Google Sheets.
* **Dashboard interactivo:** Interfaz estética *Cyber Dark* con soporte para capas de Google Maps (Satélite, Calles y Cyber Dark).
* **Acceso restringido:** Módulo de autenticación seguro en el Dashboard para proteger la visualización de coordenadas e imágenes.

## 🛠️ Tecnologías
* HTML5 / CSS3 / JavaScript (ES6)
* Leaflet JS & Google Maps API
* Google Apps Script
* Google Sheets & Google Drive API

## 🔒 Seguridad
Las credenciales de acceso al Dashboard se gestionan y verifican de forma remota contra la base de datos en Google Sheets, garantizando que ninguna información sensible o geográfica quede expuesta públicamente.
